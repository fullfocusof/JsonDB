# JSON-хранилище

Приложение, демонстрирующее работу с сложными структурами данных.

Данная библиотека предоставляет удобный интерфейс для работы с большими и сложными JSON-структурами, сохраняя их в файловой системе с возможностью частичного чтения и обновления выбранных узлов без необходимости полной загрузки файла в память.
